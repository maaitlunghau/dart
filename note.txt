NOTE
--------------------------------
I. LIBRARY
- Mỗi file Dart (.dart) mặc định là 1 library.


II. VISIBILITY
- Dart không có khái niệm public / private như Java.
- Chỉ có 2 mức visibility:

+ Có "_" phía trước:
  -> Library-private
  -> Chỉ code trong cùng library mới truy cập được.

+ Không có "_" phía trước:
  -> Public
  -> Code ở library khác có thể truy cập thông qua import.


III. PRIVATE GIỮA NHIỀU FILE
- Nếu 2 file thuộc cùng 1 library:
  -> Có thể truy cập các thành phần _private của nhau.
- Vì vậy, library-private không đồng nghĩa với private trong 1 file.
